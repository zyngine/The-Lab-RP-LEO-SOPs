# Arrests & Radio

## Before an arrest

* Establish probable cause
* State the charges clearly
* Read Miranda rights where applicable

## Processing

* Search the suspect
* Inventory belongings
* File the report
* Apply realistic sentencing

## Radio codes

| Code | Meaning |
|---|---|
| `10-8` | In service |
| `10-7` | Out of service |
| `10-20` | Location |
| `10-80` | Pursuit |
| `10-13` | Officer down |

## Radio etiquette

Keep transmissions short and clear. No shouting, no talking over each other. **Priority traffic overrides everything.**

## Warrants and raids

**Search warrants** require valid probable cause and supervisor approval.

**Raids** require:

* Four officers minimum
* A scene commander assigned
* EMS notified where appropriate

!!! tip "Sentencing"
    Realistic means proportionate. A sentence long enough that the player logs off is a scene that ends badly for everyone, including the officers who wanted a story out of it.
