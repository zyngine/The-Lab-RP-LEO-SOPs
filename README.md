# LSPD SOP

Internal procedure for the Los Santos Police Department, built with
MkDocs Material and published via GitHub Pages.

**This is a separate repository from the player rulebook on purpose.**
Nothing in the public rulebook's navigation links here, and the site
carries a `noindex` so it does not turn up in search results.

Understand what that does and does not achieve: on free GitHub Pages the
published site is **public**. An unlisted URL is obscurity, not privacy.
Anyone given the link can read it, and while this repository is public
the same content is readable directly on GitHub. That is an acceptable
trade for a PD SOP; it would not be for anything genuinely sensitive.

**Edit a page:** change the file in `docs/`, commit to `main`, and the
site rebuilds itself.
**Add a page:** create `docs/whatever.md` and add it to `nav:` in
`mkdocs.yml`.
